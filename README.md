لوحة تحكم **ثابتة** (Discord Components V2) لإرسال الرسائل الجماعية والفردية للأعضاء بالأزرار فقط، مع إحصائيات مباشرة ورسالة **Broadcast Control** ثابتة يوقف منها العضو استقبال البرودكاست نهائيًا. بوت **مستقل تمامًا** — ملف واحد، بلا أي ارتباط بأي بوت أو مشروع آخر.

---

## المتطلبات

- Node.js 22.13 أو أحدث
- تفعيل Server Members Intent من Developer Portal
- صلاحيات البوت: View Channels, Send Messages, Embed Links
- مجلد `data/` على قرص دائم

## التشغيل

```
npm install
npm start
```

أضف المتغيرات في الاستضافة أو في ملف `.env`:

| المتغير | الوصف |
|---|---|
| `DISCORD_TOKEN` | توكن البوت |
| `OWNER_ID` | معرّف المالك |
| `ADMIN_IDS` | اختياري، معرّفات مسموح لها باللوحة |
| `ADMIN_ROLE_IDS` | اختياري، رتب مسموح لها باللوحة |
| `DM_DELAY_MS` | الفاصل بين الرسائل، الافتراضي 1500 |
| `DEFAULT_LANG` | `ar` أو `en` |

## الإعداد

1. `/setup control channel:#قناة` لرسالة Broadcast Control.
2. `/setup panel channel:#قناة` للوحة.

الأمران للمالك فقط. الرسالتان تُعاد إرسالهما تلقائيًا إن حُذفتا.

## الإرسال

زر الإرسال لجميع الأعضاء أو لشخص، ثم:

- النوع: نص عادي، إمبيد، أو V2
- الصيغة: عنوان ووصف، أو وصف فقط
- صورة اختيارية (رابط https)
- زر اختياري يفتح قناة تحددها، وتكتب نصه
- في V2: زر للفاصل بين الفقرات، وزر للترقيم

بعد المحتوى تظهر معاينة ثم تأكيد الإرسال. كل رسالة تحمل منشن العضو ورابط الموقع ورابط إيقاف البرودكاست. من يضغط Stop Broadcast لا تصله رسائل بعدها.

اللوحة تعرض آخر إرسال والإجمالي، والإرسال المنقطع يكمل من حيث توقف.
